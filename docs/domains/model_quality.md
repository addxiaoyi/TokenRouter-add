# 模型能力检测

模型检测运行固定 `reasoning-v1` 题集，保存安全的公开结果。它复用提供商测试和系统用量记录；连接测试的日常维护见[提供商维护](../operations/provider_maintenance.md)。

<a id="assessment_contract"></a>
## 检测规则

1. 题集包含 8 道计算、逻辑、代码、结构化输出和上下文题，答案严格匹配，JSON 题比较结构。所有题都收到完整答案才计算分数；超时、截断、无正文或协议错误均为未完成，不算答错。
2. 每题最多运行 60 秒，请求输出上限 1024 token。整项任务预算 9 分钟；系统同时只允许一项排队或运行任务，失败不自动重发。供应商消耗进入系统模型用量，用户余额不因管理员测试扣费。
3. 当前支持有完整响应检查和输出预算的 OpenAI、Anthropic、Gemini、Kimi、DeepSeek、Zhipu API Key 文本模型。模型来自提供商配置；不满足这项执行契约的提供商仍可使用普通连接测试。
4. 每题前验证管理员仍有效、模型仍配置且私有配置指纹不变。配置变化会结束为未完成，不把不同配置的答案混成一轮分数。

<a id="assessment_persistence"></a>
## 任务与恢复

| 状态 | 处理 |
| --- | --- |
| queued | 等待单个 worker 领取；客户端 UUID 防重复提交 |
| running | 每题后保存进度，写入必须匹配当前租约 UUID |
| complete | 全部题目已回答，可成为同配置基线 |
| incomplete | 保留已完成题目，不自动重新调用供应商 |

运行租约为 10 分钟。进程退出尝试保存部分进度；崩溃后的过期任务转为未完成，旧 worker 无法继续写入。管理员刷新页面后可从服务端恢复当前任务进度。

<a id="public_reports"></a>
## 公开报告与比较

1. 公开历史最多 200 条，只包含名称、模型、题集版本、题目结果、时间和耗时。提供商 ID、操作者、配置指纹、凭据和原始回答不进入公开响应。
2. 可比较记录共享不透明 series UUID。基线必须来自相同提供商、模型、配置和题集，在当前检测前 30 天内完成。下降至少 25 分提示复测，不能将固定题集分数当作模型身份或全部能力证明。
3. 导入的旧站报告保留原检测时间和题集，使用独立历史系列，避免在新提供商配置未核验时自动充当新检测基线。
