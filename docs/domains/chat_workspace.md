# 聊天工作台与本地历史

工作台通过现有 API 网关发送文本对话，模型发现和计费遵循所选 API Key 的分组、权限与资金规则。网关行为见[路由与计费](routing_and_billing.md)，本节记录浏览器会话和客户端接入边界。

<a id="conversation_lifecycle"></a>
## 会话与请求

| 阶段 | 规则 |
| --- | --- |
| 选择 | 读取个人有效 Key，通过该 Key 查询 `/v1/models` |
| 发送 | 保存用户消息，调用 `/v1/chat/completions` 流式接口 |
| 完成 | 保存回复、模型与更新时间，展示已报告用量和耗时 |
| 中止或失败 | 保留收到的文字，不自动重发；已产生用量仍可能计费 |
| 账号变化 | 中止在途请求，清空 Key 和页面状态，加载新账号历史 |

流解析保留跨网络分片的 UTF-8 字符与 SSE 事件。显式错误、没有终态的断流和截断回复显示失败状态。用户主动停止时保留部分内容，重新发送是一次独立计费请求。

<a id="local_history"></a>
## 本地历史

1. 历史按账号 ID 保存到浏览器，包含文本、模型、标题和时间，不包含 API Key。最多保存最近 50 条会话；存储失败显示提示，内存中的内容仍可导出。
2. JSON 导入先校验格式和大小，再合并不重复的会话。未知字段不进入保存结果。删除和重命名只影响本机历史。
3. 旧站的共享存储无法证明账号归属，因此需要用户显式选择导入。读取时保留原始旧站存储；不会在登录时自动将共享历史分配给当前账号。

<a id="client_connections"></a>
## 客户端接入

`/chat2link` 提供网关地址和 NextChat、LobeChat 接入链接。生成链接前说明密钥将交给目标客户端；页面不自动打开第三方网站。链接只保留在内存中，账号或 Key 变化时清空，用户应避免分享包含密钥的链接。
