Claude Code 怎么接入？

  1. 在模型广场选择支持 Claude Code 所需协议的模型和分组。
  2. 在 API 密钥页创建密钥，选择对应分组，并打开客户端配置。
  3. 使用 Claude Code 配置中的基础地址、认证信息和模型 ID，详见Claude Code 接入教程。

如何评估回答质量？

结合自己的任务比较回答、工具调用和错误记录。分组名称与渠道标注可以帮助理解配置；性能结论需要结合模型、请求条件和测量范围判断。

常见问题

Claude API 的模型名和价格在哪里看？

在模型广场搜索 Claude，查看当前模型 ID、分组、协议和价格。创建 API 密钥时选择相应分组，再使用该分组实际提供的模型。

Claude Code 应该使用哪个地址？

Claude Code 使用 Anthropic 协议。站点的基础地址为 https://api.star-mc.top，Messages 接口路径为 /v1/messages；请使用 API 密钥页生成的客户端配置和模型 ID。

Free 组可以调用 Claude 吗？

以模型广场当时列出的 Free 组模型为准。Free 组从 Lv.1（累计 7 XP）起开放：每完成一天签到得 1 XP，每位成功注册并绑定邀请关系的好友得 1 XP，断签保留已得经验。

经验进度见经验等级页。具体分组权限同时受账号设置影响。
