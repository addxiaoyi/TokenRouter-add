免费分组与经验

Free 组需要达到几级？

从 Lv.1 起开放，累计门槛为 7 XP。达到等级后，账号仍需符合具体分组的权限设置。

签到和邀请分别给多少经验？

每个已完成的唯一签到日期贡献 1 XP，每位成功注册并绑定邀请关系的好友贡献 1 XP。两种来源合并累计，断签保留已得经验。

后续等级的门槛是多少？

Lv.1、Lv.2、Lv.3、Lv.4 的累计门槛分别是 7、21、42、70 XP。首次升级需要 7 XP，此后每级升级所需 XP 增加 7。

打开模型广场，或查看Free 分组完整说明。

接入与使用

OpenAI 兼容客户端怎么配置？

Base URL 使用 https://api.star-mc.top/v1，填写 Helstare API 密钥及所选分组中的模型 ID。接口类型按该模型支持的协议配置。

Claude Code 怎么配置？

Claude Code 使用 Anthropic 协议，标准基础地址为 https://api.star-mc.top。到 API 密钥页选择 Claude Code，复制生成的地址、认证信息和模型配置。

打开 API 密钥页，或查看Claude Code 接入教程。

怎样判断某个分组适合自己的应用？

结合目标模型的协议、当前计价、账号权限与自己的请求结果判断。比较延迟或可用情况时核对时间范围和样本量，模型质量需要结合实际任务观察。
