DeepSeek API 怎么接入？

  1. 在模型广场确认模型 ID、分组和协议。
  2. 在API 密钥页创建相应分组的密钥。
  3. 使用 OpenAI 兼容客户端时，将 Base URL 设置为 https://api.star-mc.top/v1，再填写密钥与模型 ID。

常见问题

DeepSeek API 的地址怎么填？

选择支持 OpenAI 兼容协议的模型后，将客户端 Base URL 设置为 https://api.star-mc.top/v1，并填写 Helstare API 密钥和模型广场列出的模型 ID。

有免费 DeepSeek API 吗？

请在模型广场确认 Free 组当前是否提供目标 DeepSeek 模型。Free 组从 Lv.1（累计 7 XP）起开放，每完成一天签到得 1 XP，每位成功注册并绑定邀请关系的好友得 1 XP，断签保留已得经验。

DeepSeek 分组的价格在哪里看？

模型广场显示当前模型和分组价格。结合输入、输出及适用的缓存计价估算费用，具体请求费用可在控制台使用记录中查看。

等级进度见经验等级页，免费分组的完整规则见Free 分组说明。
