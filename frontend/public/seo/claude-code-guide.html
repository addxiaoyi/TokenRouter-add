Claude Code 接入配置：地址、密钥与模型

Claude Code 使用 Anthropic 协议。Helstare 的标准基础地址为 https://api.star-mc.top，Messages 请求路径为 /v1/messages。在 API 密钥页选择 Claude Code，可以获得对应模型和分组的客户端配置。

打开 API 密钥页 查看模型与分组 接入文档

第一步：选择模型并创建密钥

在模型广场确认目标模型与协议，登录后在 API 密钥页创建对应分组的密钥。填写客户端时使用自己的 Helstare 密钥，保管好认证信息。

第二步：使用 Claude Code 客户端配置

打开 API 密钥页的客户端配置，选择 Claude Code 和所用终端，复制页面生成的环境变量。配置包括基础地址、认证信息与模型 ID；按当前页面生成的值填写。

配置含义
ANTHROPIC_BASE_URL标准入口使用 https://api.star-mc.top
ANTHROPIC_AUTH_TOKEN填写当前 API 密钥
ANTHROPIC_MODEL填写所选分组提供的模型 ID

OpenAI 兼容客户端使用的 Base URL 是 https://api.star-mc.top/v1。为 Claude Code 配置时，使用页面生成的 Anthropic 基础地址。

第三步：查看模型与请求结果

启动客户端后，确认所用模型与配置一致。需要排查错误或费用时，在控制台查看使用记录，并核对当前密钥所属分组、模型协议和账号权限。

常见问题

Claude Code 的基础地址怎么填？

标准 Anthropic 入口的基础地址为 https://api.star-mc.top，对应 Messages 路径为 /v1/messages。ANTHROPIC_BASE_URL 使用基础地址；具体值和认证变量以 API 密钥页生成的 Claude Code 配置为准。

Claude Code 的模型名应该填什么？

使用所选分组当前提供的实际模型 ID。模型广场用于查询，API 密钥页可以按模型和协议生成客户端配置。

可以使用 Free 组吗？

需要先达到 Lv.1（累计 7 XP），再确认 Free 组当前目录支持所用模型和客户端协议。每天完成签到得 1 XP，每位成功注册并绑定邀请关系的好友得 1 XP，断签保留已得经验。
