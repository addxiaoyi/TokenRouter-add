Grok API 怎么接入？

  1. 在模型广场搜索 Grok，选择目标模型与分组。
  2. 在API 密钥页创建密钥，并选择所用客户端配置。
  3. 使用 OpenAI 兼容客户端时，将 Base URL 设置为 https://api.star-mc.top/v1，填写密钥与模型 ID。

常见问题

Grok 当前有哪些模型和分组？

在模型广场搜索 Grok，查看当前模型 ID、分组、协议和价格。账号可绑定的分组以 API 密钥页为准。

Grok API 怎么配置？

目标模型支持 OpenAI 兼容协议时，Base URL 使用 https://api.star-mc.top/v1，并填写 Helstare API 密钥与模型 ID。其他客户端按 API 密钥页生成的配置接入。

Free 组可以调用 Grok 吗？

以模型广场的 Free 组当前目录为准。Free 组从 Lv.1（累计 7 XP）起开放，每完成一天签到得 1 XP，每位成功注册并绑定邀请关系的好友得 1 XP，断签保留已得经验。

经验进度见经验等级页。分组名称和说明用于了解配置，回答质量与延迟需要结合实际请求记录判断。
