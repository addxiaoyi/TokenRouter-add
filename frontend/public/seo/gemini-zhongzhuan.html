Gemini API 中转接入与分组查询

在 Helstare 使用 Gemini 时，先确认目标模型支持的接口，再选择客户端配置。模型广场列出的模型 ID、分组、协议和价格是当前接入的查询入口。

Gemini 分组如何选择？

项目需要确认的内容
协议客户端使用的接口是否在目标模型支持范围内
模型 ID使用模型广场列出的实际 ID
分组与价格在模型广场查看当前计价与可选分组
权限在 API 密钥页选择账号可使用的分组

Gemini API 怎么接入？

  1. 在模型广场搜索 Gemini，选择模型和分组。
  2. 在API 密钥页创建密钥，打开所用客户端的配置说明。
  3. 复制对应的地址、密钥和模型 ID。OpenAI 兼容配置使用 https://api.star-mc.top/v1，其他客户端按对应协议配置。

常见问题

Gemini 当前支持哪些模型？

在模型广场搜索 Gemini，查看当前可选模型、模型 ID、分组和协议。可用范围以当时的目录和账号权限为准。

Gemini 可以使用 OpenAI 兼容客户端吗？

所选模型和分组支持 OpenAI 兼容协议时，可将客户端 Base URL 设置为 https://api.star-mc.top/v1，并填写 Helstare API 密钥和模型 ID。使用 Gemini 客户端时，请选择 API 密钥页生成的对应配置。

Free 组包含 Gemini 吗？

请在模型广场查看 Free 组当前目录。该组从 Lv.1（累计 7 XP）起开放，每天完成签到得 1 XP，每位成功注册并绑定邀请关系的好友得 1 XP，断签保留已得经验。

累计经验与升级进度见经验等级页，账号可绑定的分组见API 密钥页。
