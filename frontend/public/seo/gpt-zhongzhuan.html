怎样比较分组费用？

比较同一模型在不同分组中的计价方式，并结合实际输入、输出及缓存用量估算费用。当前单价和分组信息见模型广场。

需要核对的项目用途
模型 ID保证客户端提交的名称与分组提供的模型一致
接口协议选择模型支持的 Responses 或 Chat Completions
价格与分组按当前计价和自己的使用量评估成本
分组权限在 API 密钥页选择账号可以使用的分组

GPT API 怎么接入？

  1. 在模型广场确认模型和接口，在API 密钥页创建对应分组的密钥。
  2. 将 OpenAI 兼容客户端的 Base URL 设置为 https://api.star-mc.top/v1。
  3. 填写 Helstare API 密钥和所选模型 ID；客户端需要 Responses 或 Chat Completions 时按模型协议配置。

如何查看请求结果？

在控制台查看请求错误与使用记录。比较回答质量或延迟时，保持模型、请求内容和客户端设置一致，并关注结果对应的时间范围。

常见问题

GPT API 的 Base URL 怎么填？

OpenAI 兼容客户端的 Base URL 使用 https://api.star-mc.top/v1，API 密钥使用在 Helstare 创建的密钥。模型 ID 和接口协议按所选分组的当前配置填写。

GPT 中转支持哪些模型和接口？

在模型广场搜索 GPT，查看当前模型 ID、分组及支持的接口。按模型标注选择 Responses 或 Chat Completions，具体配置可从 API 密钥页生成。

如何获得 Free 组权限？

累计 7 XP 达到 Lv.1 后可获得免费公开分组资格。每天完成签到得 1 XP，每位成功注册并绑定邀请关系的好友得 1 XP，断签保留已得经验；可调用模型以 Free 组当前目录为准。

经验和可用权限见经验等级页与API 密钥页。
