第一步：确认模型和协议

核对目标模型实际 ID 以及支持的接口。OpenAI 兼容客户端、Claude Code 和 Gemini 客户端按各自协议配置；API 密钥页提供对应客户端的配置入口。

要确认的项目在 Helstare 的查询位置
模型 ID、分组与协议模型广场
账号可以绑定的分组API 密钥页
经验等级与免费资格经验等级页

第二步：按当前计价估算费用

结合模型和分组的当前价格，按自己的输入、输出和缓存用量估算。需要比较实际支出时，在控制台使用记录中核对具体请求费用。

第三步：结合请求记录观察可用情况

查看请求是否成功、响应时间与错误类型。阅读可用率或延迟统计时，核对时间范围、样本数量和分组；这些条件决定数据能说明的范围。

第四步：查看渠道和使用限制

阅读分组说明和使用限制，确认账号权限及客户端要求。渠道名称可以帮助理解配置，服务表现需要结合实际请求观察。

问题需要查看的内容
客户端能否接入？模型协议、密钥所属分组和生成的客户端配置
当前是否有权使用？账号状态、分组权限与使用限制
是否适合当前任务？自己的回答结果、工具调用和请求记录

第五步：确认 Free 组资格

Helstare Free 组从 Lv.1（累计 7 XP）起开放。每天完成签到得 1 XP，每位成功注册并绑定邀请关系的好友得 1 XP，两种来源合并累计，断签保留经验。当前可调用模型在模型广场的 Free 组中查询。

常见问题

选择中转站先看什么？

先明确目标模型和客户端需要的接口，再查看当前模型 ID、分组计价、使用限制及账号权限。Helstare 的这些信息可从模型广场和 API 密钥页查询。

怎样比较价格和可用情况？

价格结合实际输入、输出与缓存用量估算。可用情况结合自己的请求记录判断，阅读统计时核对时间范围、请求数量和错误类型。

怎样获得 Helstare Free 组资格？

累计 7 XP 达到 Lv.1 后获得免费公开分组等级资格。每天完成签到得 1 XP，每位成功注册并绑定邀请关系的好友得 1 XP，断签保留已得经验；当前模型与具体分组权限以站内页面为准。
